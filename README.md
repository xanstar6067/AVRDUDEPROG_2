# AVRDUDE PRO

Компактная WPF-оболочка для AVRDUDE, которая сохраняет функциональность AVRDUDE_PROG 3.3 и делает опасные операции явными.

## Возможности

- запись, проверка и чтение Flash/EEPROM;
- Drag & Drop прошивок с проверкой содержимого файла;
- Intel HEX (`.hex`, `.ihex`, `.ihx`, `.a90`, `.eep`), Motorola S-Record, AVR ELF, raw binary и текстовые списки байтов;
- 72 микроконтроллера и 11 программаторов из комплекта AVRDUDE_PROG 3.3;
- поиск микроконтроллера, автоматическое запоминание МК, программатора, порта, файлов и размера окна;
- профили автоматического программирования;
- чтение калибровочной ячейки и явный chip erase;
- комплект старого драйвера USBasp в выходной папке.

## Безопасность fuse-битов

Обычные Flash/EEPROM-команды никогда не содержат `lfuse`, `hfuse`, `efuse`, `fuse` или `lock`. Перед любой записью приложение отдельно читает fuse, а после записи снова читает и сравнивает их. Автоматического восстановления или скрытой записи нет.

AVRDUDE 6.1 safemode отключён аргументом `-u`, потому что safemode способен самостоятельно пытаться восстановить изменившиеся fuse. Его заменяет явная защита приложения:

1. fuse/lock сначала обязательно читаются с устройства;
2. редактируются только биты, разрешённые таблицей МК; зарезервированные значения сохраняются с устройства;
3. непосредственно перед записью выполняется повторное чтение и проверка, что снимок не устарел;
4. показываются точные изменения байтов и битов;
5. пользователь вводит `ЗАПИСАТЬ` в отдельном окне подтверждения;
6. lock записывается последним;
7. после записи выполняется контрольное чтение и полное сравнение.

Важно: запись Flash вызывает chip erase. Он не переписывает fuse, но аппаратно снимает lock-биты и может стереть EEPROM, если `EESAVE = 1` (бит не запрограммирован). Интерфейс предупреждает об этом перед операцией.

## Сборка и проверка

```powershell
dotnet build .\AVRDUDEPROG2\AVRDUDEPROG2.slnx
dotnet run --project .\AVRDUDEPROG2\AVRDUDEPROG2.Tests\AVRDUDEPROG2.Tests.csproj --no-build -- .
```

Настройки сохраняются в `%LOCALAPPDATA%\AVRDUDEPROG2\settings.json`. Файлы AVRDUDE, конфигурация, USBasp-драйвер и лицензия автоматически копируются в выходную папку.

Аппаратные операции требуют реального программатора и целевого AVR. Самотесты не выполняют запись на устройство.
